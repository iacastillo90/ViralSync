# Especificación de Superposiciones Gráficas (9:16 Overlays)

## 1. Tarjeta Flotante de Producto (Tercio Superior)
- **Dimensiones:** Ancho 800px, Alto adaptativo según margen interno (padding 20px).
- **Posicionamiento:** Centrado horizontalmente `(1080 - 800) / 2 = 140px`, Y = 120px desde la parte superior.
- **Fondo:** Rectángulo con esquinas redondeadas (radio 24px) y color `rgba(15, 23, 42, 230)` (slate oscuro).
- **Borde:** Contorno de 3px en dorado `#EAB308`.
- **Imagen de Producto:** Escalada proporcionalmente a un máximo de 180x180px con margen de 15px.

## 2. Badge Glassmorphism de Subtítulos (Tercio Inferior)
- **Dimensiones:** Ancho 920px, Alto 180px.
- **Posicionamiento:** Centrado horizontalmente `(1080 - 920) / 2 = 80px`, Y = 1600px desde la parte superior.
- **Fondo:** Caja con 85% de opacidad `rgba(15, 23, 42, 217)`.
- **Tipografía:** `DejaVuSans-Bold.ttf`.
- **Formato de Texto:** 
  - Primera palabra / Gancho: Tamaño 42pt, Color amarillo `#FACB15`.
  - Cuerpo de la frase: Tamaño 36pt, Color blanco `#FFFFFF`.
